## 🚀 Estructura de Entregables

El contenido de este tema se organiza de la siguiente manera:

* 🧩 **AST y Módulo Lexer Híbrido**: `./AST Y MÓDULO LEXER HÍBRIDO/`  
  * Implementación combinada de un árbol sintáctico abstracto (AST) y un lexer híbrido que utiliza expresiones regulares y tablas de símbolos.

* ⚖️ **Comparación LL vs LR & Asistente Híbrido**: `./Comparacion LL vs LR & Asistente Hibrido/`  
  * Análisis comparativo entre parsers LL y LR, con un asistente interactivo que muestra pasos de parsing.

* 🐳 **DockerNetworks**: `./DockerNetworks/`  
  * Laboratorios de redes Docker para experimentar con contenedores y análisis de tráfico a nivel de compilación.

* 🦈 **dockerlexer**: `./dockerlexer/`  
  * Lexer especializado para archivos Dockerfile, con pruebas unitarias y soporte para Docker Compose.
