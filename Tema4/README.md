# 📚 Tema 4: Análisis Léxico

Este directorio contiene todas las actividades y entregas correspondientes al **Tema 4** de la asignatura *Lenguajes y Compiladores*.

---

## 📄 Documento Base Teórico
* 📘 **Informe Principal**: [`Informe/`](./Informe)
  * Documento académico que contiene el desarrollo formal del marco teórico sobre el análisis léxico, expresiones regulares, autómatas finitos deterministas (AFD), metacompiladores léxicos (FLEX) y su aplicación en la tokenización de lenguajes de programación.

---

## 🚀 Estructura de Entregables
El contenido de este tema se organiza de la siguiente manera:

* 🐳 **Analizador Léxico para Dockerfile**: [`Actividad2_Docker/`](./Actividad2_Docker)
  * Implementación de un analizador léxico (lexer) para archivos `Dockerfile` utilizando expresiones regulares en Python. Incluye ejecutable compilado para Windows y tres archivos de prueba con distintos escenarios (válido, con errores léxicos y con comentarios).
* 🦀 **Analizador Léxico para Rust con FLEX**: [`Actividad3_Rust_Flex/`](./Actividad3_Rust_Flex)
  * Implementación práctica de un analizador léxico automatizado para un subconjunto estructurado del lenguaje Rust, desarrollado con el metacompilador FLEX. Genera un AFD que tokeniza palabras reservadas, identificadores, números, operadores y delimitadores.
